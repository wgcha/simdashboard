# 의미 매핑 합성 예제

실제 업무 데이터 없이 CSV와 JSON을 같은 결과 항목으로 읽는 예제다.

1. 관리자 의미 매핑 화면에서 `definitions.json`을 반입한다. 새 항목 ID로 연결된 두 레시피와 한 템플릿이 초안으로 저장된다. 같은 키가 이미 있으면 자동 덮어쓰지 않는다.
2. `예제 CSV 읽기`를 열고 `result.csv`를 샘플로 선택해 새 레시피 버전을 저장한다. `예제 결과 위젯 6종`을 선택해 미리보기 후 레시피·템플릿을 함께 활성화한다.
3. 결과 파일 등록 화면에서 대상 하중 경우를 선택하고 같은 파일을 등록한다. 값은 최대 응력 120 MPa, 최대 변위 2 mm, 시간 0~1초의 응력 곡선이며 게이지는 기준 150 MPa에 대해 PASS다.
4. JSON 레시피도 `result.json`으로 같은 방식으로 검증한다. 두 형식의 원본 구조는 다르지만 결과 항목 ID·관측값·위젯 입력은 같다.

폴더 새로고침을 시험하려면 설정한 SPDM 루트 안에 임의 이름의 폴더를 만들고 파일을 복사한 뒤 기존 하중 경우와 활성 레시피를 연결한다. 예제 반입은 실제 프로젝트나 폴더를 자동 생성하지 않는다.
