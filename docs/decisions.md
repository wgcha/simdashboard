# 결정 기록

확정된 결정을 날짜·근거와 함께 1줄씩 누적한다.

- 2026-10-02 · 폴더 역할을 폴더별 지정에서 Root 기준 깊이별 정의(DEPTH_V1)로 전환 · 동일 역할 반복 지정 비용 제거 · `docs/contracts/depth-schema.md`
- 2026-10-02 · 상위 구간(Root→프로젝트→의뢰) 깊이는 관리자가 지정, 전역 1개 · 사업부 등 중간 폴더 구조 대응
- 2026-10-02 · 의뢰 이하는 표준 깊이 강제(Working 필수, 유통 RunOption 필수), 이탈은 "확인 필요" · 추측 등록 방지
- 2026-10-02 · 깊이 스키마는 환경별 전역 1개, 프로젝트별 재정의 없음 · 유연성보다 사용성
- 2026-10-02 · 환경은 의뢰명 부분일치(사용/유통), 둘 다/없음은 확인 필요 · 폴더명 규칙 단순화
- 2026-10-02 · 구형 `WR_x_SimType1|2` 의뢰명 규칙 삭제 · 더 이상 사용하지 않음
- 2026-10-02 · 정의된 마지막 깊이보다 깊은 폴더는 역할 없는 내용물로 허용 · Scene 하위 결과 구조 자유
- 2026-10-02 · 사용환경 EVALUATION 역할을 SCENE으로 통합 · 두 환경의 Case 결과·Final 로직 단일화
- 2026-10-02 · 스키마 저장 시 기존 등록 의뢰는 불변, 의뢰별 수동 "재해석"으로만 적용 · SPDM 결과 연결 변경 위험 통제
