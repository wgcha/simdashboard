# ADR 0005: Windows Server 2022 폐쇄망 배포 대상 추가

- 상태: 승인된 구현 방향, 실제 Server 2022 릴리스 검증 대기
- 날짜: 2026-09-14
- 근거: 사용자가 Windows Server 2022만 존재하는 폐쇄망의 신규 설치 및 기존 DB 업데이트 설치를 명시적으로 요청함.
- 대체 범위: [ADR 0004](0004-canonical-production-deployment-target.md)의 Windows 운영 배포 제외 조건. Rocky 운영 경로는 유지한다.

## 결정

Windows Server 2022 x64를 별도 설치 대상에 추가한다. 소스 실행용 Node/Vite 구성과 서버 운영용 Caddy 정적 웹 + loopback FastAPI + Windows 서비스 구성을 구분한다. 외부 Windows 빌드 PC에서 대상 서버에 필요한 바이너리·의존성을 모두 묶고, 폐쇄망에서는 반입된 패키지만 사용한다.

신규 로컬 PostgreSQL과 기존 PostgreSQL 연결을 모두 제공한다. 기존 DB는 검증한 백업 이후 대기 중인 스키마 변경만 적용한다. 데이터 삭제·DB 교체·PostgreSQL 메이저 업그레이드를 일반 설치나 업데이트에 포함하지 않는다. 기존 계정과 인증 키는 보존한다.

## 구현 경계

- 소스 준비, DB 준비, 패키징, 서비스 설치를 기능별 스크립트/모듈로 분리한다.
- 운영 상태와 릴리스 파일을 분리하고 신규·업데이트에 같은 DB 백업/스키마/계정 도구를 사용한다.
- 패키지 해시 검사는 운송 중 무결성을 확인한다. 배포자 신원 확인은 조직의 서명/반입 승인 절차로 별도 수행한다.
- 인터넷 ACME 발급은 설치 기본 흐름에 포함하지 않는다. 사내 HTTP 및 조직 인증서 HTTPS 운영 정책을 명시한다.
- 기존 native Windows 애플리케이션 기능 제한은 별도로 추적하며 설치기 지원을 해당 기능 검증으로 표현하지 않는다.

## 수락 기준

[시나리오와 검증 행렬](../windows-deployment-scenarios.md)의 신규 설치, 기존 DB 업데이트, 재부팅 후 서비스, 폐쇄망 무통신, 실패 시 중단 검증을 실제 Windows Server 2022 VM에서 수행한다. 모의 시험과 패키지 빌드 성공은 각각 별도로 기록한다.
