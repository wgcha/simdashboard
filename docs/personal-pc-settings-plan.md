# 내 PC 설정 기본 메뉴

2026-09-09 사용자 요청: PC 도우미를 작업 실행 내부의 숨은 기능이 아니라 모든 사용자가 웹에서 개인화하는 기본 기능으로 제공한다. 상태: 회원가입·독립 설치 구현 완료. 최신 API와 검증은 [개인 회원가입과 PC 도우미 설치](personal-onboarding-implementation.md)를 따른다.

## 사용자 흐름

- 사이드바 기본 메뉴 `내 PC 설정` → `/workspace/settings/local-pc`. 활성 계정이면 프로젝트·작업·관리자 권한이나 관리자 메뉴 노출 정책과 관계없이 접근한다. 프로젝트가 없는 최초 구성 화면에서도 진입 버튼을 제공한다.
- 계정과 현재 PC 연결 상태를 표시한다. 도우미 미실행 상태에서도 페이지와 시작 안내가 보인다.
- `PC 도우미 설치 파일 받기`는 현재 웹 주소·자동 시작 선택·검증된 배포 manifest를 담은 Windows BAT를 내려받는다. 로그인·PC 비밀값은 넣지 않는다. 웹 주소의 `/api` 프록시를 사용하므로 내부 백엔드 호스트를 추정하지 않는다.
- 최초에는 받은 파일을 실행하면 서버의 Windows 배포 ZIP을 검증하고 사용자 로컬 경로에 설치한다. Git·전체 소스·별도 Python 설치나 기존 서버 폴더 선택은 필요 없다. 자동 시작은 선택값에 따라 현재 Windows 사용자에게만 등록한다.
- 웹에서 다시 확인 → 이 PC 연결 → 기존 네이티브 승인창 한 번 확인. 이후 계정·PC별 자동 연결을 복원한다.
- 이 화면에서 프로그램 자동 검색·버전별 선택 등록·키워드·실행 경로를 관리한다. 실제 업무 실행은 작업 실행 화면의 기존 권한·담당자 검사를 따른다.

## 구현 경계

`features/local-pc`는 개인 설정 화면과 시작 파일 생성을 맡는다. 공통 연결 생명주기는 `shared/local-execution/useManagedLocalConnection.ts`로 이동해 실행 화면과 설정 화면이 같은 인증·갱신 규칙을 재사용한다. 중앙 계정-PC API, 로컬 카탈로그와 실행 권한 계약은 유지한다.

기본 개인 메뉴는 프런트엔드 내장 메뉴로 제공하고 중앙 업무 메뉴 정책의 편집 대상으로 추가하지 않는다. 비활성·미승인 계정은 접근할 수 없다. 관리자 권한을 확대하지 않으며 API는 기존 로그인과 본인 연결 소유권을 검사한다.

## 확인할 내용

- 관리자·일반 사용자·프로젝트 없는 계정에서 기본 메뉴와 직접 주소 접근.
- 도우미 미실행 안내와 시작 파일 다운로드, 주소·옵션·특수문자 안전성, Windows PowerShell 5.1 구문.
- 연결/재연결/해제, 계정 전환 시 토큰과 이전 카탈로그 제거.
- 프로그램 검색·등록·수정·삭제가 실제 API에 반영되고 작업 실행에서도 같은 목록 사용.
- 데스크톱·좁은 화면, TypeScript·구조 검사 및 기존 로컬 실행 회귀.

## Git 배포 상태

최초 요청 시점에는 PC 도우미 코드와 원클릭 업데이트기가 미커밋 상태여서 Git에서 받은 버전에 기능이 없었다. 2026-09-09 후속 요청으로 관련 구현·검증 기록과 PostgreSQL 실행 가이드를 `codex/windows-one-click-deploy` 브랜치에 함께 게시한다. 사내에서는 이 브랜치를 받은 뒤 `update.bat`로 빌드·migration·재시작을 완료해야 새 메뉴가 나타난다. 원격 반영 성공 여부는 push 결과와 원격 커밋으로 확인한다.

## 후속 요청: 사용자 PC 전용 도우미 설치기

사용자가 다중 사용자 운영을 재확인하며 이 보완을 기억해 두도록 요청했다. 최초에는 계획으로만 기록했으나, 2026-09-09 후속 요청으로 회원가입과 함께 구현했다. 최신 범위와 검증 상태는 [개인 회원가입과 PC 도우미 설치](personal-onboarding-implementation.md)를 따른다.

- 공용 서버에 Workbench 웹/API와 PostgreSQL을 두고, 각 사용자 PC에는 도우미와 업무 프로그램만 설치한다.
- 웹의 `내 PC 설정`에서 도우미 전용 설치 파일을 제공한다. 사용자 PC에 Workbench 전체 소스, Git, 서버 배포 폴더 또는 별도 Python 설치를 요구하지 않는다.
- 설치 경로는 사용자별 로컬 기본 경로로 자동 지정한다. 설치 후 현재 웹 계정과 해당 PC를 연결하고, 프로그램 탐지·파일 선택·실행은 그 PC에서 수행한다.
- 서버 배포 폴더를 선택하게 하던 임시 시작 파일을 독립 설치 방식으로 대체했다. 서버에 검증된 Windows ZIP이 준비되지 않았으면 설치 버튼을 비활성화하고 배포 준비 안내를 표시한다.
- 최초 연결 승인, 계정-PC별 카탈로그와 이력 분리, 사용자별 자동 시작을 유지한다. 서버 DB 선택·설정과 사용자 PC 도우미 설치는 별도 흐름으로 안내한다.
