1. 기능별 구조도

각 화면 요청은 상단의 공통 API 클라이언트와 서버 인증·권한 경계를 통과합니다. 아래 가로선은 화면과 담당 서버 기능의 대응 관계를 간단히 나타냅니다.

2. 데이터 연결도

업무 문맥 · 결과 등록 · 조회

화면·업무 문맥 처리 단계 조회 결과 저장 위치 기존 새로고침 경로

새 등록 화면은 SPDM 상위 업무를 새로 만들지 않습니다. 게시가 DB에서 성공한 뒤 SPDM 원본 복사가 실패하면 수집 버전은 보존되고 복구 상태가 표시됩니다. 기존 폴더 새로고침은 별도의 수집 경로입니다.

범위: 현재 주요 연결만 요약했습니다. PC 도우미 코드는 남아 있지만 현재 작업 실행 화면의 도우미 패널과 연결 요청은 숨겨져 있어 본선 흐름에서 제외했습니다. DuckDB는 로컬 개발용 DB adapter입니다.
근거: 현재 아키텍처 · 결과 등록 계약 · SPDM 저장 폴더 연계
