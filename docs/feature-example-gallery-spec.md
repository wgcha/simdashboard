# 기능 예제 갤러리 사양

문서 버전: 1.0

## 1. 목적

기존 Orion 샘플과 사용자가 등록한 데이터를 변경하지 않고, 주요 기능의 정상·경고·대기 상태를 반복해서 확인할 수 있는 독립 예제와 진입 화면을 제공한다. 예제는 제품 기능의 기대 결과와 확인 순서를 함께 설명한다.

## 2. 화면

- 좌측 메뉴에 `예제 갤러리`를 추가한다.
- 카드에는 범주, 목적, 기대 상태, 포함 기능, 데이터 구성, 확인 목록과 바로가기 버튼을 표시한다.
- 범주 필터와 텍스트 검색을 제공한다.
- `WARN`, `NO DATA`, `BLOCKED`는 오류가 아니라 해당 상태의 처리 방식을 설명하기 위한 의도된 예제임을 명시한다.
- 컨텍스트가 있는 예제는 프로젝트·의뢰·하중 경우를 선택한 뒤 `상세 분석`, `Run 비교`, `워크플로`, `변수 카탈로그` 중 지정 화면을 연다.

## 3. 시드 데이터

모든 레코드는 `project-feature-showcase` 아래에 `INSERT OR IGNORE` 방식으로 추가하며 기존 레코드를 덮어쓰지 않는다.

| 예제 | 핵심 데이터 | 기대 결과 |
|---|---|---|
| Run 비교 | 3 Run, 4개 공통 정량 변수, 공통 시계열 | 회귀 1, 개선 1, 유지 2 |
| 신뢰도 정상 | 2 Run, 원본·체크섬·스키마·파서·Validation, 수치·곡선·이미지 | `TRUSTED` |
| 신뢰도 경고 | 2 Run, 미등록 위치 변수, Validation 없음 | `WARN` |
| 협업 검토 | 2 Run, 북마크·의견 3건 | `OPEN`, `IN_REVIEW`, `RESOLVED` |
| 다중 결과형 | 수치, 시계열, 곡선, 이미지, 위치 | 5개 결과형 조회 |
| 데이터 대기 | 결과 없이 NUMBER, TIME_SERIES, IMAGE, VIDEO, MODEL_3D 선언 | 카탈로그 `데이터 대기` |
| 워크플로 | 10단계 요청 처리 | 완료·진행·차단·대기 혼합 |

폴더 스키마, PPT 시각적 레이아웃, 자동화 실행 이력, 결과 등록, 도움말은 기존 기능으로 연결되는 추가 카드로 제공한다.

## 4. API

`GET /api/feature-examples`

- 안정적인 예제 ID와 관련 화면 컨텍스트를 반환한다.
- 데이터베이스에서 현재 Run·정량·시계열·곡선·미디어·검토 개수를 집계해 카드의 `data_profile`로 반환한다.
- 갤러리 설명은 예제 계약이며 데이터 변경 API가 아니다.

## 5. 데이터 모델 원칙

- 신규 업무 테이블은 추가하지 않는다.
- 기존 `projects` → `analysis_requests` → `load_cases` → `analysis_runs` 계층과 결과형 테이블을 그대로 사용한다.
- 출처 추적은 `analysis_run_metadata`, 폴더 적재는 `folder_import_jobs`, 품질 확인은 `validations`, 검토는 `result_bookmarks`와 `review_annotations`을 사용한다.
- 변수 선언과 실제 값은 분리한다. 데이터 대기 예제는 `variable_definitions`만 있고 결과 테이블에는 값이 없다.

## 6. 수용 기준

1. 갤러리에 12개 이상의 기능 카드가 표시되고 범주·검색 필터가 동작한다.
2. Run 비교 예제는 회귀 1건, 개선 1건, 유지 2건을 반환한다.
3. 신뢰도 정상 예제는 `TRUSTED`, 경고 예제는 `WARN`을 반환한다.
4. 검토 예제에 세 상태의 의견이 각각 존재한다.
5. 다중 결과형 예제에서 수치·시계열·곡선·이미지·위치를 조회할 수 있다.
6. 데이터 대기 예제의 선언 변수는 `has_data=false`다.
7. 기존 Orion 예제, 대시보드, 보고서 레이아웃과 판정 로직은 변경하지 않는다.
