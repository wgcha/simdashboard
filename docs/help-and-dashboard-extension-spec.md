# 사용 시나리오 도움말 및 해석 대시보드 추가 확장 사양

문서 버전: 1.0

## 1. 목적

기존 분석·편집 기능을 변경하거나 제거하지 않고, 사용자가 하려는 작업을 기준으로 화면과 데이터 흐름을 안내한다. 해석용 대시보드의 신뢰성을 높이는 기능은 추가형으로 제공한다.

## 2. 도움말 진입과 구성

- 좌측 메뉴에 `도움말`을 추가한다.
- 기능 목록보다 사용 시나리오를 먼저 보여준다.
- 각 시나리오는 목적, 순서, 주의사항, 관련 화면으로 이동하는 버튼을 제공한다.
- 첫 제공 시나리오:
  1. 새 해석 결과 등록과 확인
  2. 폴더 결과·변수 카탈로그·대시보드 연결
  3. 편집 가능한 PPT 보고서 생성
  4. 대시보드 레이아웃 추가·저장·복구
- PostgreSQL은 현재 DuckDB 실행과 구분해 “전환 구현 후 사용”임을 명시한다.

## 3. 대시보드 추가 개선 원칙

- 기본 화면과 기존 저장 레이아웃은 유지한다.
- 새 기능은 메뉴, 위젯, 필터 또는 저장 가능한 레이아웃으로 추가한다.
- 선언 변수에 데이터가 없으면 `데이터 대기`를 표시한다.
- 차트에는 출처 변수, 단위, 기준, 최신 결과 시점을 추적할 수 있어야 한다.
- 대시보드와 PPT는 같은 `variable_key` 계약을 사용한다.
- 레이아웃 변경은 버전으로 기록하고 복구 가능해야 한다.

## 4. 후속 업그레이드 후보

1. 결과 최신성·적재 상태·검증 경고를 보여주는 데이터 품질 위젯
2. 여러 해석 Run을 겹쳐 비교하는 버전/Run 비교 탭
3. 판정 기준 변경 전후 영향을 계산하는 What-if 보조 화면
4. 변수별 출처 파일과 파서 이력을 여는 데이터 계보 패널
5. 보고서 출력 이력과 생성 파일을 연결하는 감사 로그

후보는 기존 판정 로직을 바꾸지 않고 별도 위젯 또는 패널로 추가한다.

## 5. 수용 기준

- 도움말 메뉴와 네 가지 시나리오가 표시된다.
- 각 시나리오 버튼이 관련 화면으로 이동한다.
- 폴더 스키마, 결과 테이블, 변수 카탈로그, 대시보드/PPT의 역할 차이가 도움말에 명시된다.
- PostgreSQL이 아직 활성 연결이 아님을 오해 없이 안내한다.
