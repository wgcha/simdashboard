# 실행 환경 운영 방향과 PC 설정 지원 중단

- 기준일: 2026-09-28
- 상태: 사용자 결정 반영. `내 PC 설정` 화면과 작업 실행의 PC도우미 패널을 비노출하며, 중앙·클라우드 실계산 실행은 후속 계획이다.

## 제품 방향

PC도우미를 통한 개인 사용자별 PC 실행 환경 설정 지원을 중단한다. 웹플랫폼은 공용 의뢰·작업·입력 조건·결과·이력 관리에 집중한다. 사용자마다 프로그램 설치 경로·버전·환경변수·계산 자원을 등록하는 방식을 기본 업무 흐름으로 제공하지 않는다.

중앙·클라우드 배치 사용 설정은 추후 보강한다. 관리자가 검증된 소프트웨어 버전과 실행 환경을 관리하고, 사용자는 업무에 허용된 환경과 입력 조건을 선택하는 방향으로 설계한다. 중앙 실행은 사내 전용 계산 PC·서버도 포함하며 외부 클라우드 도입을 전제하지 않는다. 웹/API·DB와 계산 실행기의 역할을 분리한다.

중앙 실행 도입 전에는 기존 업무 환경에서 해석을 실행하고 플랫폼의 기존 결과 등록·조회 기능을 이용한다. 현재 중앙 실행 이력 수집 기능을 중앙 실계산 기능으로 안내하지 않는다.

## 이번 변경 범위와 보존 계약

- `내 PC 설정` 메뉴, 초기 진입 링크, 로그인 화면의 도우미 연결 권유를 제거한다. 기존 설정 URL로 접근해도 PC 설정 화면을 노출하지 않는다.
- 계정 관리와 글자 크기·기본 조회 화면 등 일반 웹 사용자 편의 설정은 PC 환경 설정 중단과 구분한다.
- 비밀번호 변경은 비밀번호 인증 모드에서 공통 사이드바의 환경설정을 통해 제공한다. 사이드바가 없는 초기 화면에서는 상단 비밀번호 변경 버튼을 제공한다. 프로젝트 이용 권한이 없는 활성 계정에는 업무 접근 안내를 표시하며 PC 설정 설치를 요구하지 않는다.
- 계정·권한·기존 PC 연결 데이터·실행 이력·사용자 파일을 삭제하지 않는다. DB migration과 배포 정책 변경은 없다.
- 작업 실행 화면에서도 PC도우미 패널을 마운트하지 않는다. PC 연결·프로그램 등록·직접/일괄 로컬 실행·패널 내 이력 영역을 숨기고, 해당 패널에서 발생하던 도우미 탐색·연결·중앙 로컬 실행 이력 요청도 발생시키지 않는다. 일반 작업 진행·완료와 기존 DEMO_ONLY 배치 기능은 유지한다.
- 이번 화면 비노출은 PC도우미 전체 제거가 아니다. 도우미 API·배포 파일·설치된 프로그램과 기존 실행 이력 데이터는 보존한다. 설치된 도우미의 자동 시작 해제·연결 종료·제거 안내와 잔존 API 정리는 후속 작업으로 다룬다. 화면 비노출만으로 기존 연결이 폐기되거나 도우미가 종료됐다고 안내하지 않는다.

## 후속 중앙 배치 설계 조건

업무별 표준 실행 환경과 버전, 입력 전달·결과 회수, 작업 폴더 격리, CPU·메모리·라이선스 대기열, 취소·장애 복구, 결과 유효성 검증을 함께 설계한다. 실행 환경의 변경 이력과 실행 당시 환경 버전을 보존한다. 개인별 절대 경로를 중앙 실행 설정으로 그대로 이관하지 않는다.

실제 제품의 무인 실행 지원·라이선스와 Windows·폐쇄망 배포 적합성을 확인해야 한다. 기존 [Windows 배포 정책](windows-deployment-policy.md)은 계속 적용한다. 중앙 실행은 아직 구현·현장 검증된 것으로 간주하지 않는다.
