# 항목 이름–값 그래프

- 요청: 결과 표 대신 항목 이름과 수치를 막대 또는 점·선으로 비교한다.
- 위젯 종류: `name_value`

## 사용 방법

상세 분석에서 **대시보드 편집 → 위젯 추가·버전 관리 → 항목 이름–값 그래프**를 선택한다. 위젯 설정의 **항목 그래프 표시 방식**에서 **막대**, **점**, **점과 선** 중 하나를 선택하고 레이아웃을 저장한다. 기존 결과 표도 위젯 설정의 시각화 유형을 바꾸어 사용할 수 있다.

표·항목 그래프·막대·시계열의 설정은 **데이터 항목** 선택기를 사용한다. 왼쪽 **미적용 항목**에서 이름·키를 검색하고 **추가**하면 오른쪽 **적용 항목**으로 이동한다. 적용 목록의 **제외**로 개별 해제하며 **검색 결과 모두 추가**, **전체 제외**로 일괄 변경한다. 검색 중에도 적용 목록은 그대로 보이고 작은 화면에서는 두 목록을 위아래로 배치한다. 기존 단일 변수 설정도 선택 목록으로 표시된다. 명시적으로 전체 제외하면 빈 위젯이 표시된다.

가로축은 항목 이름이고 세로축은 값이다. 점과 선은 항목 표시 순서를 연결하며 시간 이력을 뜻하지 않는다. 이름이 길거나 항목이 많으면 그래프 내부를 가로로 스크롤하여 확인한다. 단위가 다른 항목은 단위별 그래프로 나눈다.

기존 막대 그래프와 시계열 그래프는 같은 축에 놓을 수 있는 동일 단위 항목을 선택한다. 시계열은 시간 단위도 일치해야 한다. 다른 표시 방식으로 변경하면 사용할 수 없는 항목을 제외하고 안내한다. 아직 결과가 없는 선언 항목은 **데이터 대기**로 표시하며 미리 선택할 수 있다.

파일 읽기 설정의 결과 위젯에서도 **항목 이름–값 그래프**를 선택할 수 있다. 숫자 결과 항목을 연결하며 벡터는 표시 성분을 지정한다. 의미 연결 위젯은 기존 막대 그래프와 동일한 단위 호환 검사를 거치므로 호환되지 않는 단위는 별도 위젯으로 구성한다.

작업 유형의 **요청 결과 위젯**에서도 같은 그래프와 표시 방식을 선택한다. 저장된 설정은 새 의뢰의 결과 구성에 반영된다. 기존 의뢰의 결과 snapshot을 자동으로 변경하지 않는다.

## 저장·배포 계약

일반 대시보드는 `settings.chartStyle`, 의미 연결 템플릿은 `chart_style`에 `bar`, `dot`, `line`을 저장한다. 생략하면 막대를 사용한다. 기존 시계열 `line`과 산점도는 유지한다. 0과 음수는 유효한 값이며 결측·비수치 값을 0으로 대체하지 않는다.

일반 표·그래프의 다중 선택은 `settings.variableIds` 배열에 저장한다. 배열이 있으면 기존 `variableId`보다 우선하고 빈 배열은 명시적 선택 없음이다. 배열이 없는 기존 위젯은 기존 단일 변수 또는 기본 표시를 유지한다. 의미 연결 위젯은 기존 `item_ids` 배열을 계속 사용한다. 값 카드·게이지·미디어 및 산점도의 X/Y 항목은 각각 단일 선택을 유지한다.

기존 JSON 위젯 설정과 Recharts를 사용한다. 신규 의존성·DB migration·배포 진입점 변경이 없으며 Windows 배포 계약을 유지한다.
